How a charter company installs it 
<script src="https://YOUR-JETRESERVE-HOST/widget.js" defer></script>
<div data-jetreserve-leg="LEG_ID"
     data-session-url="/your-backend/jetreserve-session"></div>

// your backend, per click:
POST /api/v1/checkout-sessions   x-api-key: <secret>   { "legId": "LEG_ID" }
  -> { "embedUrl": "...", "token": "jrs_...", "expiresAt": "..." }
